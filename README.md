# Decision Maker App

A simple desktop app that helps you make decisions.

## Description

Decision-maker is an Electron application where users can add 2 or more choices and let the app randomly select one option.

### Technologies Used
- Electron
- JavaScript
- HTML
- CSS
- Node.js
- Aseprite (pixel-art assets)

### Features

- Add custom choices
- Randomly select one option
- Pixel-art inspired interface
- Animated result screen
- Custom desktop application window

## Getting Started

### Dependencies

The application requires:

- Node.js
- npm (Node Package Manager)
- Electron

### Installing

Clone the repository:

```
git clone https://github.com/yourusername/decision-maker.git
```

Install dependencies:

```
npm install
```

Run the app:

```
npm start
```

### Executing program

1. Press Start.
2. Add as many options you like.
3. Press Decide.
4. The app will randomly select one of your choices.
