# Decision-Maker App

A simple desktop app that helps you make decisions.

## Description

Decision-maker is an Electron application where users can add 2 or more choices and let the app randomly select one option.

### Technologies Used
- Electron
- JavaScript
- HTML
- CSS
- Node.js
- Aseprite

### Features

- Add choices
- App randomly selects one option
- Pixel-art interface
- Animated cat

## Getting Started

### Dependencies

The application requires:

- Node.js
- npm (Node Package Manager)
- Electron

### Installing

Clone the repository:

```
git clone https://github.com/yourusername/decision-maker.git
```

Install dependencies:

```
npm install
```

Run the app:

```
npm start
```

Or download the latest version from [Releases](https://github.com/nadira-03/decision-maker/releases/latest) and install Decision.Maker.Setup.1.0.0.exe.

### Executing program

1. Press Start
2. Add as many options as you like
3. Press Decide
4. The app will randomly select one of your choices
